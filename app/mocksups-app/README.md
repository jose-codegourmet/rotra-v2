# ROTRA mockups

These HTML files are the canonical editable prototypes. From the repository root run:

```bash
nvm use && pnpm mockups
```

Open [Queue](http://127.0.0.1:3003/queue-app/rotra-queue.html), [Player Information](http://127.0.0.1:3003/player-app/rotra-player.html), or [Admin](http://127.0.0.1:3003/admin-app/rotra-admin.html). Stop the server with Ctrl+C. Each product directory also contains its prototype notes.

The prototypes use fictional browser-local demo data. Browser storage is scoped to its origin, so opening them on this server may start a fresh demo compared with a file URL or another host or port; the old origin's data is not transferred.
