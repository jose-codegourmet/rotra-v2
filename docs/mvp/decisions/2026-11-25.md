### D-2026-11-25-01 — The regression suite runs on the Go API and a plain Postgres
- **Decision status:** approved (owner, 2026-11-25, track `regression-go_20261125`).
- **Implementation status:** implemented on the branch of ticket [#1097](https://github.com/jose-codegourmet/rotra-v2/issues/1097) (epic #869).
- **Ticket:** [#1097](https://github.com/jose-codegourmet/rotra-v2/issues/1097).
- **Roadmap:** MVP — [Queue](../workstreams/queue.md) (verification).
- **Decision:** replaces the local-Supabase part of [D-2026-11-12-05](2026-11-12.md#d-2026-11-12-05). The rest of that decision (the pass rules, the fairness rule, the Done review, offline excluded, not in `make check`) stands.
  - **What runs:** the three apps in real mode with `ROTRA_GO_API_URL` set and `ROTRA_GO_MOVED_AREAS=/api`, so every `/api` call goes to the Go API, on a throwaway Postgres container (`rotra-e2e-pg`, `127.0.0.1:54329`, database `rotra_disposable_e2e`). No Supabase, no Supabase CLI, no `psql`.
  - **Guardrails:** `src/guard.ts` allows only that database and a loopback Go API URL, and refuses any Supabase variable with a value. The Go API's own start-up check allows the same host, port and name.
  - **Test clock in Go:** allowed, test-only. It is compiled only with the `e2e` build tag, is off unless `ROTRA_E2E_CLOCK=1`, refuses to start unless `DATABASE_URL` is the local throwaway database, serves its control endpoint on `127.0.0.1` only, and never runs earlier than real time. One clock for everything, sign-in included (the apps check the Go pass on their own virtual clock). The simulation client refreshes once on 401 `expired` and retries, as the real apps do.
  - **Accounts:** the seed writes the first admin's `auth_identities` and `admin_accounts` rows as SQL (argon2id from Node's built-in `crypto.argon2Sync`); the club and the players come from the product's routes.
  - **Findings:** a difference in behavior is a `bug` issue under #869 and the test is marked `knownDefect`. A route that is missing in Go is a backlog item, not a bug, and the test is skipped with that item's id.
