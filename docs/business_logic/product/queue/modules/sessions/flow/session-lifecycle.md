# Flow: prepare and run a session

1. Online, the licensed operator creates the session on up to three pages: date, venue and courts (required); formats, mode and minimum; costs and review. **Create session** works from page 1, using defaults for the rest.
2. Prepare slots using saved club players, Player Information suggestions, or new entries. Assign each a full level. Remove anyone who will not come.
3. Download the session on each device that may run it offline.
4. Mark players present as they arrive. Only present players enter automatic generation.
5. Start the session once every roster player has a level. Levels lock.
6. Build the shared waiting queue with Manual, Make match, Suggest, or Auto queue. Start each match yourself on a free court.
7. Add late arrivals if needed, including offline. Their level locks when added.
8. Add or remove free courts and extend time as the night requires.
9. Confirm each winner or invalid match to release its court(s). Watch the live leaderboard.
10. Finish or invalidate every game still in play.
11. Online, with everything synced and reconciled, press Session done. Acknowledge any minimum-game shortfall; missing device records cannot be ignored.
12. Valid finalization updates Player Information and creates private slides. Publishing and image downloads are separate.

An already-active session may finish and sync after license expiry, but another cannot start without renewal.
