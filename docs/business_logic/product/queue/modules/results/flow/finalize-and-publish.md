# Flow: finalize and share session results

1. Finish or invalidate every game still in play. Session done stays blocked while any game is active.
2. Online, the operator presses Session done and reviews games recorded, participants, sync state, and waiting matches that were never played (they are dropped from results).
3. Confirm that records are synced and reconcile device interruptions. If incomplete, follow recovery; do not generate provisional final slides offline.
4. If players are below the minimum, review the shortfall list; the operator can still close a complete session.
5. Confirm Session done. Valid finalization syncs eligible profiles and performance and updates overall ranking/leaderboard eligibility automatically.
6. Prepare the private three-slide wrap-up. Apply history requirements for Most Improved and Off Day.
7. The operator reviews the slides and decides whether and when to publish, and separately whether to download images.
8. Include Off Day only after an explicit choice in that publish or download. Use club branding with “powered by rotra”.
9. Publish again later to change what is shared; Off Day starts unselected every time.

An invalid session stops before steps 5–9. Result review is a sharing decision, not an opportunity to change already-confirmed winners or scores.
