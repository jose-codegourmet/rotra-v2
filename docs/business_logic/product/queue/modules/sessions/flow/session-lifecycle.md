# Flow: prepare and run a session

1. Online, the licensed operator creates the session on up to three pages: date, venue and courts (required); formats, mode and minimum; costs and review. **Create session** works from page 1, using defaults for the rest.
2. Prepare slots using saved club players, Player Information suggestions, or new entries. Assign each a full level. Remove anyone who will not come.
3. Download the session on each device that may run it offline.
4. Mark players present as they arrive. Only present players enter automatic generation.
   - **Calling it off instead?** Before Start session, **Cancel session** (optional reason) makes it Cancelled: final, read-only, counts nowhere; roster, waitlist and payment marks are kept, refunds happen outside ROTRA, join requests close and the public page says Cancelled. To play anyway, create a new session. See [Cancelling a session](../README.md#cancelling-a-session-owner-decision-november-6-2026).
5. Start the session once every roster player has a level. Levels lock and the actual start time is recorded; it stays fixed. Starting after the planned end or on another day first asks for a new end time.
6. Build the shared waiting queue with Manual, Make match, Suggest, or Generate matches. Put each match on a free court yourself (Manual Queue) or let Auto Queue place the next ready one; either way, you start each match yourself with Start match.
7. Add late arrivals if needed, including offline. Their level locks when added.
8. Add or remove free courts and set the end time (any time after now, or Extend 30/60 min) as the night requires. Past the planned end, the console reminds you; the session never closes by itself.
9. Confirm each winner or invalid match to release its court(s). Watch the live leaderboard.
10. Finish or invalidate every game still in play. Matches On court but never started are dropped like waiting matches.
11. Online, with everything synced and reconciled, press Session done. Acknowledge any minimum-game shortfall; missing device records cannot be ignored.
12. Valid finalization updates Player Information and creates private slides. Publishing and image downloads are separate.

An already-active session may finish and sync after license expiry, but another cannot start without renewal.
