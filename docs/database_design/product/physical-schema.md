# Physical schema (drafted)

**Last verified:** 2026-10-31.

**Status:** Draft Prisma models and **unapplied** migration SQL in `packages/db/prisma/`. Each migration
needs human sign-off before it touches any database ([coding conventions §13](../../coding-conventions.md#13-database-later-epic)).
Decision gates #243–#248 are still open; every choice below that depends on them is marked.

Common to every table: UUID keys (`uuid(7)` generated by the client) unless noted, `timestamptz(6)`
instants, `revision bigint default 1` on mutable records, money as integer minor units plus a
`char(3)` currency. All application tables have `REVOKE ALL … FROM anon, authenticated`: they are read
only through server Route Handlers and services, never through the Supabase Data API.

## Group A · shared references, clubs, accounts (F07.9 · `20261031000100`)

| Table | Keys and uniques | Checks | Delete behavior |
|---|---|---|---|
| `location_codes` | PK `id`; unique `(country_code, city_code)` | country `^[A-Z]{2}$`, city `^[A-Z]{3}$` (registry rules pending #244) | Referenced with `RESTRICT` |
| `skill_levels` | PK `id smallint`; unique `code`, `display_order`, `(category, band)` | `display_order` 0–8; seeded with exactly nine rows | Reference data, never deleted |
| `clubs` | PK `id`; unique `name_key`, `source_command_id`; index `founding_location_code_id` | non-blank name; currency `^[A-Z]{3}$`; players per court 2–20; default fee null or ≥ 0; kept prices > 0 when present; paid ⇒ both prices and yearly < 12 × monthly | `RESTRICT` to founding location |
| `club_accounts` | PK/FK `club_id`; unique `username`, `(auth_provider, auth_subject)` | username already trimmed + lowercase; `provisioned_at` ⇒ `auth_subject` | `RESTRICT` to club |
| `admin_accounts` | PK `id`; unique `(auth_provider, auth_subject)` | — | — |

- `clubs.name_key` is the service-written comparison key (`clubNameKey` in `@rotra/db/admin/club-identity`:
  NFKC, trim, collapse whitespace, lowercase). The approved comparison is pending #245.
- A free club may hold no prices (new tester club) or its last paid prices; physical nullability is
  pending #245. Price changes never touch `club_license_terms`.
- Credentials stay in Supabase Auth. Club and admin accounts map to a provider subject, never to a
  `players` row. `club_accounts.auth_subject` is null until staged provisioning succeeds.
