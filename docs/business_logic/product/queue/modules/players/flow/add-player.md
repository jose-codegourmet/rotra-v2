# Flow: add and confirm a player

1. Open **Add player** from preparation, or **Add late player** from the live console. The sheet names the target session.
2. Search **Saved players** by name, nickname, or RTR ID. Pick one who is not already in the session.
3. If they are new to the club, search **Player Information** (online only). Pick a candidate. For an unclaimed profile, confirm identity with the player: RTR ID matches, scanned their QR, or phone confirmed; do not link by name alone. A registered (claimed) profile needs no identity check and is added in one tap at its Player Information level.
4. Otherwise choose **New player**: name, optional nickname, optional phone. Without a phone they are saved as a guest. With one, they are marked Lookup pending.
5. Choose the level for this club. It starts at the Player Information suggestion when there is one. In a live session it locks immediately.
6. **Confirm player slot.** The player joins the roster and the club's saved list. In preparation they start not present; in a live session they start present.

## Offline arrival

An unexpected player can join a downloaded session as a new player with name, level, and optional phone. Player Information search waits for reconnection; permanent RTR IDs are not generated offline.

## Returning incomplete profile

Collect missing details or issue a registration link. The link claims/completes a profile; it does not reserve or confirm session slots. See [registration](../../../../player-information/modules/identity/flow/claim-and-recover.md).
