# Admin-reviewed password reset requests

Status: IN MOCK APP — #491 (PR #494)

Owner request: submitting Forgot password creates a request under Admin > Requests, with no automatic email. An authorized Admin verifies ownership and provides a single-use, expiring reset link. The player chooses their own password.

Updated Player Forgot password receipt and Admin navigation + Password resets screen. Retains the existing card, notice and action patterns in both themes. Admin confirms ownership before generating/replacing a link; copying is separate from delivery. Unknown contacts remain private to Admin and cannot produce a link. No new delivery channel or evidence-upload requirement.
