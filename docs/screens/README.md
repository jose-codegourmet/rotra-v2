# ROTRA screen specifications

Start with the [product screen index](product/README.md) or the requested [product modules](product/modules/README.md).

**Status:** Complete screen-contract draft for the agreed v1 scope, October 25, 2026; Queue screens updated October 26, 2026 to match the [ROTRA Queue prototype](../frames/queue-app/rotra-queue.html). This specifies intended experience, not implemented routes or shipped screens. No application code is changed.

The module files cover surfaces, controls, field rules, permissions, loading/empty/error states, offline behavior, confirmations, and acceptance examples. Unresolved business rules are explicitly listed rather than answered by invented UI behavior.
